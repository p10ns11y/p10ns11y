# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Hiring managers and technical peers evaluating Peramanathan Sathyamoorthy's work — primarily through a SpaceXAI-class filter. The hiring reader decides whether to reach out; the peer reader decides whether to collaborate or remember the name. Both land on the GitHub profile page.

## Product Purpose

Attract inbound that would not happen from a standard CV or LinkedIn. The profile must make someone reach out who otherwise would scroll past — by surfacing a unique architectural lineage (2015 energy-efficiency orchestration → 2026 agent harnesses) backed by live, clickable code rather than claims.

## Positioning

A single engineer whose 2015 thesis boxes (orchestrator, context, knowledge graph, control, wisdom) keep reappearing in 2026 agent stacks — with git-dated evidence, not retconned marketing. The profile proves this with running repos, not slogans.

## Operating Context

GitHub profile README rendered as markdown. No framework, no build step. The reader sees it on github.com/p10ns11y or as a hover card. Badge shields, collapsible details, and aligned divs are the full toolbox. External links point to live Vercel deploys, npm packages, IEEE/Wiley papers, and X posts.

## Capabilities and Constraints

- Must remain a single README.md (GitHub profile repo renders only this file).
- GitHub markdown subset only: no custom CSS, no JS, no raw HTML beyond what GitHub sanitizes (div, details, summary, sub, sup, img, a, br, tables, badges).
- All external links must point to live, reachable targets.
- No fabricated testimonials, metrics, or claims. Every fact must have a git date or external source.

## Brand Commitments

- Identity: Peramanathan Sathyamoorthy / p10ns11y.
- Voice: direct, evidence-first, no-BS, occasionally wry. Never corporate or self-congratulatory.
- Tagline and badges are open to evolution if the result is more beautiful and precise.

## Evidence on Hand

- IEEE CloudCom 2015 paper, Wiley 2017 paper, Uppsala thesis (hosted PDF + DiVA).
- 15+ public repos with git history proving the timeline.
- npm packages since 2017.
- Grok testimonial (GROK_TESTIMONIAL.md).
- Live deploys: devprofile CV, thepulimaangani metre tool, v0-live-feed, selfie sign-in.
- X posts and articles with timestamps.

## Product Principles

1. **Evidence over assertion** — every claim links to a commit, paper, or deploy.
2. **Reward the careful reader** — depth is layered (progressive disclosure via details/summary), not dumped.
3. **Beauty within constraint** — maximize craft within GitHub markdown's limits; never fight the medium.
4. **Truth, honesty, reality** — no invented metrics, no inflated scope, no borrowed glory.
5. **Precision** — each word earns its place; remove what a careful reader would skip.
