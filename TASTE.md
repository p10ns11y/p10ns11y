Voice and judgment for `README.md`. Product truth lives in `PRODUCT.md`; structure lives in `DESIGN.md`.

## Voice

Direct, evidence-first, no-BS, occasionally wry. Never corporate or self-congratulatory. Every claim earns a link — commit, paper, deploy, or dated repo.

- **Sorkalam:** built fast; **used while writing** Energy Efficiency as an Orchestration Service. Popup = meaning (Wiktionary, Tamil Virtual University). Grok/Grokipedia = **subject and more context**, open out so the extension **does not pay API bills**.
- **devprofile `/qa`:** **xAI Collections** chunks and embeds on upload. App only `documents/search` + Grok. No own chunker / embed model / Pinecone. Local `qa-index.json` = fallback. Say **xAI**, not “they.”
- **prompt-tuning-lab:** harvest stays local. Distill LLM sees **tidied turns only** — not raw harness or agent dotfiles.
- **AgenC protocol:** **fork** — timeline only, not Featured as original.
- **Harness:** **tweaked** Grok Build; **slight** token/$ wins. Full quality/perf eval **paused** on quota. Target: quality per token per watt.
- **Spine:** identity → 2015 machine (table) → running now (3) → connect → inch (git dates) → Featured (thepulimaangani first) → Cooking → POCs → Long arc = evidence + limit, **do not repeat the table**.

## Anti-goals

- Over-clean: removing shields, badges, or personality for minimalism
- Over-minimalize: collapsing the architecture table or Featured into one paragraph
- Invent proof: fabricated benchmarks, employer signals, rotting status tables
- Billboard hero: download-first kanithanj CTA above identity
- Essay opening: dense prose before the first clickable proof
- Hidden contact: Connect in nested `<details>`
- Repeat the table: Long arc is evidence + limits, not a second mapping
